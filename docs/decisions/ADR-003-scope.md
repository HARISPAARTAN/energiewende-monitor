# ADR-003: Umfang der ersten Version

Datum: 2026-10-25 · Status: angenommen

**Entscheidung.** Version 1 enthält das Marktgebiet DE-LU ab 2023-01-01 viertelstündlich, den stündlichen
Day-Ahead-Preis und die MaStR-Kapazität je Bundesland. Die vier Regelzonen (50Hertz, Amprion, TenneT,
TransnetBW) folgen stündlich in Meilenstein 5 über denselben Code (`--regions`).

**Begründung.** Genug Daten für Vorjahresvergleiche, Ladezeit unter 15 Minuten, überschaubares DAX.
